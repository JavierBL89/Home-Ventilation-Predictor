🔍 Ventilation Time Prediction: Model Overview

This app i capable of predicting the the most optimal time to ventilate our home using three different forecasting models. Each model is trained with fake indoor and outdoor temperature fluctuations data of a whole year to analyze trends and generate future predictions.
See training data graph

Weather prediction days are limited to the next upcooming 3 day because of free teer infrasctructure.
We have adjusted the outputs taking into consideration that you will never ventilate your home at 4am, so the results are shown from 6am to 00pm. Below is how each model works and how we’ve applied them.

📘 1. SARIMAX (Seasonal ARIMA with Exogenous Variables)

  • Type: Traditional Statistical Model
  • Best for: Capturing short-term dependencies, trends, and lag effects (The most recent hours, days, or weeks)
    Here we use it for the next 72h
  • Key Feature: Requires data to be stationary (data do not change over time).

🔧 Workflow:

  1. Stationarity Check: We run the Augmented Dickey-Fuller (ADF) test to determine if the indoor temperature data is stationary. If not, we apply differencing to remove trends.

  2. Model Training: We train SARIMAX with the transformed temperature data using the (p,d,q) order determined either manually or via auto_arima(). We include daily seasonality with parameters like (1,1,1,24) for 24-hour cycles.

  3. Forecasting: We generate hourly indoor temperature predictions. Outdoor temperatures are interpolated to match indoor forecast resolution. We compare the two to determine the best, morning, and evening times to ventilate the home.

📕 3. TimesNet (Time-Series Transformer)

  • Type: Deep Learning Transformer
  • Best for: Complex, multi-step dependencies and long-term temporal patterns
  • Key Feature: Learns temporal dynamics with attention mechanisms

🔧 Workflow:

  1. Pretrained Model: We use a pretrained version of TimesNet hosted on Hugging Face. Our pipeline feeds it hourly indoor temperature sequences.

  2. Model Input: The past 24–48 hours of indoor temperatures are formatted into the model’s input format. Outdoor temperatures are interpolated as context (optional extension).

  3. Inference & Prediction: TimesNet outputs the next 48 indoor hourly predictions. We align these with the interpolated outdoor data to determine:
    • 🕐 Best Time
    • 🌅 Morning Option
    • 🌇 Evening Option
    • 🌀 Alternatives

🔄 Logic Behind All Models

All models follow the same ventilation decision logic:

  1. Forecast indoor temperature (SARIMAX / Prophet / TimesNet).
  2. Interpolate outdoor forecast from OpenWeather API.
  3. Detect the hour with maximum difference:
    • In summer: ventilate during the coolest indoor vs. outdoor gap (e.g., late night).
    • In winter: ventilate during the warmest difference (e.g., midday).

This logic is season-aware, allowing the app to give different suggestions per season.


❓ Why Are the Results Sometimes Different?

Each model makes different assumptions about the data:

  • SARIMAX: assumes past patterns will continue, and can't easily adjust to sudden changes.
  • TimesNet: is more flexible and powerful but can overfit or behave unpredictably unless trained on extensive data, which is not the case, but results show well accuracy to what is expected
